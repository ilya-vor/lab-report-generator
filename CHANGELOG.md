# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/), версии SemVer.

## [1.0.0] - 2026-10-15

Первый рабочий выпуск (Лабораторная работа №1).

### Added
- `generate_scheme.py`: построение BPMN 2.0 и визуализации PNG/SVG для
  процесса «As-Is: периодический контроль применения СИЗ на сварочном участке».
- `build_report_docx.py`: сборка отчёта из шаблона с клонированием титула и
  рамки-колонтитула.
- Документация: `README.md`, `HISTORY.md`, `docs/*`.
- Скрипты `update_fields.ps1`, `build_all.ps1`.

### Fixed
- Порядок операций в `build()`: `clear_content` -> `patch_title_page` ->
  `build_content` (иначе дублировалось наполнение).
- Ширины колонок штампа: длинная группа «КАИД-104М» больше не переносится
  на вторую строку (титул остаётся на 1 странице).
- Замена группы, разбитой на runs, в `header1.xml`.
- Вертикальное зеркалирование координат BPMN под ось Y Camunda.
- Цвета проблемных зон перенесены в BPMN (`bioc:fill` / `bioc:stroke`).
- Убрано имя пула в BPMN (оставлены только подписи дорожек).

### Changed
- Схема сделана компактнее (шаг колонок, высота дорожек, шрифты).
- Подписи таблиц без курсива.
