# Новая лабораторная

1. Создайте `labs/labN_<тема>.py` по образцу `labs/lab2_siz.py`:
   - константы темы: `PAGE_TITLE` (на титул), `SHORT_TITLE` (в шапку),
     `frame_title` (в рамку, короче), `OUT_NAME`;
   - функции схем через `labkit.schemes` (`Box`, `Link`, `render`);
   - `build_content(rep)` - текст отчёта;
   - `build()`: нарисовать схемы, собрать `ReportMeta`, `prepare()`,
     `build_content()`, `save()`.
2. Добавьте модуль в `LABS` в `build.py` (`{"3": "labs.lab3_xxx"}`) и в
   `choices` аргумента `--lab`.
3. Соберите: `python build.py --lab 3 --pdf`.
4. Схему-эскиз удобно сначала отрисовать и посмотреть PNG в `out/`,
   потом править координаты: итерации дешевле, чем проверка в Word.

## Чек-лист ЛР2 (структурная схема управления)

- [ ] Есть объект управления и субъект управления (ЛПР + средство автоматизации).
- [ ] Показана прямая связь (управляющее воздействие) и обратная связь
      (характеристика процесса, а не просто «данные»).
- [ ] Учтена внешняя среда (возмущения) и информационная база (БД/ERP).
- [ ] Есть вход и выход процесса.
- [ ] Вторая схема раскрывает субъект управления на функции/модули.
- [ ] Каждая схема подписана «Рисунок N. ...» и упомянута в тексте до рисунка.
- [ ] Таблицы: подпись сверху, ссылка в тексте до таблицы.
- [ ] Титул на одной странице (группа не переносится).
- [ ] Оглавление обновлено, номера разделов не прилипают к заголовкам.
- [ ] Нет длинных тире.

## Чек-лист ЛР1 (BPMN As-Is)

- [ ] Есть начальное/конечное события, узлы по дорожкам, исключения через XOR,
      покрытие >= 80 %.
- [ ] Есть минимум 3 проблемные точки с обоснованием.
- [ ] Титул на одной странице (группа не переносится).
- [ ] Оглавление обновлено.
- [ ] Нет длинных тире.
