# Новая лабораторная

1. Создайте `labs/labN_<тема>.py` по образцу `labs/lab2_siz.py`:
   - константы темы: `PAGE_TITLE` (на титул), `SHORT_TITLE` (в шапку),
     `frame_title` (в рамку, короче), `OUT_NAME`;
   - функции схем через `labkit.schemes` (`Box`, `Link`, `render`,
     `render_ishikawa`);
   - `build_content(rep)` - текст отчёта;
   - `build()`: нарисовать схемы, собрать `ReportMeta`, `prepare()`,
     `build_content()`, `save()`.
2. Допишите пару в `LABS` в `build.py`: `{"3": "labs.lab3_xxx"}`. Всё,
   `--lab 3` появится в вариантах автоматически.
3. Соберите: `python build.py --lab 3 --pdf`.
4. Схему удобно сначала отрисовать и посмотреть PNG в `out/`, потом править
   координаты: итерации по картинке дешевле, чем проверка в Word.
5. Проверьте разбиение на страницы по PDF (y-координаты блоков), а не на
   глаз: `Heading 1` принудительно начинает раздел с новой страницы.

## Чек-лист схемы управления (как в ЛР2)

- [ ] Один субъект управления (ЛПР + средство автоматизации), объект шире
      самого мониторинга.
- [ ] Прямая связь - управляющее воздействие глаголами: остановить,
      провести, допустить.
- [ ] Обратная связь - состояние объекта (факт нарушения), выход - сводная
      оценка (статус).
- [ ] Внешняя среда влияет и на объект, и на субъект.
- [ ] Есть вход и выход процесса, информационная база (БД/ERP).
- [ ] Вторая схема раскрывает субъект управления на модули с входами/выходами.

## Чек-лист оформления

- [ ] Каждая схема подписана «Рисунок N. ...» и упомянута в тексте до неё.
- [ ] Таблицы: подпись сверху, ссылка в тексте до таблицы, шапка повторяется.
- [ ] Титул на одной странице (группа не переносится).
- [ ] Оглавление обновлено, номера разделов не прилипают к заголовкам.
- [ ] Каждый раздел занимает целое число страниц (без «пустых» хвостов).
- [ ] Нет длинных тире, диапазоны вида `4-8` сохранены.
