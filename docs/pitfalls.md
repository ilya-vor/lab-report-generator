# Грабли

- **Титул на 2 страницы**: длинная группа переносится -> расширить «Группа»,
  сузить «Фамилия И.О.» в `fix_stamp_widths` (`_STAMP_W`).
- **Дублирование наполнения**: неверный порядок в `build()`. Нужно
  `clear_content` -> `patch_title_page` -> `build_content`.
- **Дорожки в BPMN наоборот**: ось Y вниз -> зеркалировать (`flip_y`).
- **Нет цветов в Camunda**: добавить `bioc:fill`/`bioc:stroke`.
- **Группа не меняется в колонтитуле**: в `header1.xml` разбита на runs ->
  `patch_group_runs` (regex).
- **Кракозябры в консоли**: cp1251 -> писать вывод в файл `encoding="utf-8"`.
- **Старое оглавление**: обновить поля через `update_fields.ps1`.
- **Длинное тире (U+2014)**: заменить связками; диапазоны и минус не трогать.
- **PNG != BPMN**: рисуют разные движки; для синхронизации экспортируйте PNG
  из Camunda.
