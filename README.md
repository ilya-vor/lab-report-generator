# lab-report-generator

Тулкит для отчётов по лабораторным работам: схемы из кода (matplotlib) и
сборка DOCX строго по шаблону кафедры. Титул, рамка-штамп, стили и содержание
клонируются из `report_template.docx`; меняется только наполнение.

## Быстрый старт

```powershell
pip install -r requirements.txt

python build.py --lab 2              # схемы + DOCX (WS Word обновит TOC)
python build.py --lab 2 --pdf        # то же и PDF
python build.py --lab 2 --no-fields  # без Word: поля/TOC останутся как в шаблоне
```

Результат - в `out/`: `*.docx`, `*.pdf` и PNG/SVG схем.

## Что внутри

| Путь | Назначение |
|------|-----------|
| `build.py` | единая точка сборки: `--lab`, `--pdf`, `--no-fields`. |
| `labkit/docxgen.py` | DOCX из шаблона: титул, рамка, TOC, таблицы, рисунки. |
| `labkit/schemes.py` | схемы: блоки, стрелки, БД, облако среды, диаграмма Исикавы, классы, варианты использования, последовательность. |
| `labs/lab2_siz.py` | ЛР2 целиком (3 схемы + текст отчёта) - образец для новых лаб. |
| `labs/lab3_sppr.py` | ЛР3: структурно-функциональная схема СППР мониторинга СИЗ. |
| `labs/lab4_ontology.py` | ЛР4: онтология организационной системы (таксономия и UML). |
| `labs/lab5_models.py` | ЛР5: системные модели (IDEF0, дерево функций, DFD, ER, UML). |
| `report_template.docx` | эталон оформления: не перерисовывается, только `TPL`-маркеры. |
| `update_fields.ps1`, `to_pdf.ps1` | поля/TOC и экспорт в PDF через Word. |
| `docs/` | конвейер, грабли, инструкция «новая лаба». |

## Правила

1. Титул и рамку не рисуем заново - клонируем из шаблона.
2. Порядок сборки: `prepare()` (очистка + титул) -> наполнение -> `save()`.
3. Тексты-маркеры шаблона живут в `TPL`, замена идёт сквозь runs.
4. Схемы - только из кода (`labkit.schemes`), чтобы они пересобирались одной
   командой вместе с текстом.
5. Разделы начинаются с новой страницы (`Heading 1` = `pageBreakBefore`),
   поэтому каждый раздел подгоняется под целое число страниц.
6. Без длинных тире; диапазоны (`4-8`) и минус в формулах сохраняем.
