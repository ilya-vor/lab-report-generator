# Онтология организационной системы предприятия

`org.ttl` - сериализация Turtle, OWL 2 DL, профиль выразительности SROIQ.

| Состав | Сколько |
|---|---|
| Классы (6 группировочных ветвей, промежуточный `Process`, 19 концептов) | 26 |
| Объектные свойства, из них 13 пар обратных | 26 |
| Свойства данных (12 ключевых из таблицы 5 и два служебных) | 14 |
| Аксиомы: несовместимости и обязательные связи | 7 |
| Индивиды пилотного участка (сварка рамы) | 30 |

Состав соответствует таблицам 4-7 отчёта `out/Воробьев_И_С_отчет_по_4_ЛР_*.docx`.
При правке модели меняются оба места: файл и таблицы в `labs/lab4_ontology.py`.

Свойства с датой объявлены как `xsd:dateTime`, а не `xsd:date`: разумщик HermiT
не поддерживает `xsd:date` и останавливается с `UnsupportedDatatypeException`.

## Открыть в Protégé

1. Запустить `C:\Users\Ilya\Apps\Protege-5.6.9\Protege.exe`: в комплекте JRE 11,
   отдельно ставить Java не нужно.
2. `File -> Open...`, выбрать `ontology/org.ttl`. Если файла не видно в диалоге,
   переключить фильтр справа внизу на `All Files`.
3. Разумщик: `Reasoner -> HermiT`, затем `Reasoner -> Start reasoner` (`Ctrl+R`).
   Если ошибок нет и классы не подсвечены красным, модель согласована.
4. Полезные вкладки: `Entities` (классы, свойства, индивиды),
   `Ontology views -> Class hierarchy`, `Object property hierarchy`,
   `OntoGraf` (граф без внешних программ; для `OWLViz` нужен Graphviz).

## Что снять на скриншот

Достаточно двух кадров:

1. `Entities -> Classes` с работающим HermiT: видно дерево из 26 классов и
   жёлтым - выведенные связи.
2. `OntoGraf` по классу `Employee` (или `Incident`): граф связей
   `worksIn`, `holdsPosition`, `caused`, `resolves`.

В подписи к скриншоту указывают версию Protégé 5.6 и разумщик HermiT.
